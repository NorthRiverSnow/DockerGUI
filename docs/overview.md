# 概要

## この道具は何か

Docker を画面から操作するデスクトップアプリ。
コンテナの一覧を見て、起動・停止し、ログを読み、コンテナの中でコマンドを実行する——
Docker を使う人が毎日繰り返す操作を、端末に打ち込まずに済ませる。

## 誰が、どの場面で使うか

Docker を日常的に使う開発者が、自分の開発機で使う。

想定する場面は次の 3 つ。

| 場面 | 端末で打つ場合 | この道具で行う場合 |
| --- | --- | --- |
| 動いているコンテナを確かめる | `docker ps` を打ち、横に長い出力を読む | 一覧の画面を見る。状態の変化は自動で反映される |
| 異常終了したコンテナのログを読む | `docker logs -f <id>` を打つ。コンテナ ID を先に調べる | 一覧から行を選び、ログの画面を開く |
| コンテナの中を調べる | `docker exec -it <id> sh` を打つ | 一覧から行を選び、端末の画面を開く |

## 対象環境

| OS | Docker の構成 | アプリが動く場所 |
| --- | --- | --- |
| macOS | Docker Desktop、colima、その他 unix ソケットを使うもの | macOS |
| Windows | Docker Desktop（WSL2 バックエンド） | Windows |
| Windows | WSL のディストロに直接入れた Docker Engine（Docker Desktop を使わない） | Windows |

**Windows でも、アプリは Windows のアプリとして動く。** アプリを WSL の中で動かす構成は対象にしない
（「対象にしないもの」を参照）。

Docker への接続先は、決め打ちにせず**利用者の環境から探して決める**。
macOS では colima のように `/var/run/docker.sock` を使わない構成があり、パスを決め打ちにすると接続できない。

## できること

| 対象 | できること |
| --- | --- |
| コンテナ | 一覧の表示、起動、停止、再起動、削除 |
| ログ | 選んだコンテナのログの表示。新しい行が出たら自動で続きを表示する |
| 端末 | 選んだコンテナの中でコマンドを実行する |
| イメージ | 一覧の表示、取得（pull）、削除 |
| ボリューム | 一覧の表示 |
| ネットワーク | 一覧の表示 |
| Compose | プロジェクトの一覧、起動（up）、停止（down）、サービスごとの状態の表示 |
| 診断 | Docker に接続できないときに、何を試して何が失敗したかを表示する |

## 対象にしないもの

**ここに挙げたものは作らない。** 作らないと決めておかないと、設計がそれらを見越した形に膨らむ。

| 対象にしないもの | 理由 |
| --- | --- |
| インストーラの作成、コード署名、公証 | 当面は開発者本人の開発機で動けばよい。署名には有償の登録と証明書が要る |
| 遠隔のホストへの接続（SSH や TCP 越しの Docker） | 対象の場面が開発機の中の Docker に限られる |
| アプリを WSL の中で動かす構成（WSLg） | 利用者に WSLg の設定を求めることになる。Windows のアプリとして動かせば設定が要らない |
| イメージの構築（build） | 構築は Dockerfile を編集しながら行う作業で、エディタと端末の側にある |
| レジストリへのログインと push | 取得（pull）だけを対象にする |
| Kubernetes と Swarm | 対象の場面に出てこない |
| 複数の Docker への同時接続 | 接続は常に 1 つ。切り替えは行えるが、同時には繋がない |

## 用語

**この表の言葉を、コードの名前とドキュメントの両方で使う。** 言い換えを増やすと、
同じものを指しているかどうかが読めなくなる。

| 言葉 | 意味 |
| --- | --- |
| Docker Engine | コンテナを実際に動かしているサーバ。以下「エンジン」 |
| Engine API | エンジンが提供する HTTP の API。この道具はここを直接叩く |
| コンテキスト | Docker CLI が持つ接続先の設定。`docker context ls` で並ぶもの |
| 接続方式 | エンジンに繋ぐ経路。「ソケット」と「子プロセス」の 2 つがある（`design.md` を参照） |
| ディストロ | WSL の中に入っている Linux の環境。`wsl.exe -l` で並ぶもの |
| 診断 | 接続に失敗したときに、何を試して何が失敗したかを調べて表示する機能 |
| 追従 | ログの画面で、新しい行が出たら自動で末尾まで表示を進めること |
